# Learn Multilevel Modeling with R and the NFL

This course is for anyone who wants to learn how to do multilevel modeling in R.

It starts from the very beginning with a Week 0 module on how to install and set up R and RStudio.

Then over the course of 10 weeks, students build up the skills to run multilevel models.

We use NFL game data to make learning R 'fun'!

The modules will be released throughout Fall 2026.
