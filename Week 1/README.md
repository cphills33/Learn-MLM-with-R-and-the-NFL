# Week 1: Set up a project and explore NFL games

## 1. Download Week 1

- Download `Week_1_Materials.zip` from the [course GitHub releases](https://github.com/cphills33/Learn-MLM-with-R-and-the-NFL/releases). Unzip it and locate the `Week 1` folder inside.

**Data credit:** The CSV is a 2025 regular-season extract of game and schedule data maintained by Lee Sharpe, obtained with the [`nflreadr` package](https://nflreadr.nflverse.com/reference/load_schedules.html).

## 2. Create an RStudio Project

1. Open RStudio and choose **File → New Project**.
2. Choose **New Directory → New Project**.
3. Give the project a name, such as `NFL-Course`, and choose where to save it.
4. Select **Create Project**. RStudio creates a project folder containing a `.Rproj` file.
5. Move the `Week 1` folder into that project folder, beside the `.Rproj` file. If you completed Week 0, you can also place your `Week 0` folder there.

Your files should look like this:

```text
NFL-Course/
├── NFL-Course.Rproj
└── Week 1/
    ├── Week_1_Worksheet.qmd
    └── data/
        └── games_2025.csv
```


## 3. Prepare to run the worksheet

- Open the `.Rproj` you created.

## 4. Complete the analysis

- follow the worksheet to analyze the data
