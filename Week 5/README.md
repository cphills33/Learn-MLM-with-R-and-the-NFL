# Week 5: Let team strength vary over time

## Set up Week 5

Download [Week_5_Materials.zip](https://github.com/cphills33/Learn-MLM-with-R-and-the-NFL/releases/download/week-5-v1.0.0/Week_5_Materials.zip) and unzip it. The archive contains a `Week 5` folder with all required lesson files.

1. Put `Week 5` inside your RStudio Project beside the previous weeks.
2. Open your `.Rproj` file and `Week 5/Week_5_Worksheet.qmd`.
3. Complete the opening setup chunks and unfinished pipelines using the written instructions.
4. Create and display your finished figure as `my_plot`.
5. Restart R and click **Render**.


## Guiding question

How does a team's scoring-margin history change during a season?

## Learning goals

- Put team-game observations in chronological order.
- Use `cummean()` and `lag()` within team groups.
- Compare an expanding average with a trailing three-game average.
- Distinguish retrospective descriptions from information available before kickoff.
- Build a line chart comparing at least two teams.
